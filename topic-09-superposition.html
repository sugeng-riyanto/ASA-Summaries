Superposition & Stationary Waves

SuperpositionDiffractionInterferenceCoherenceYoung’s Double-SlitDiffraction GratingStationary Waves
EXAMINER’S BRIEF

One principle — the resultant displacement is the algebraic sum of individual displacements — powers diffraction, interference and stationary waves. Memorise the two path-difference conditions cold, quote the slit/grating equations, and always state the node–antinode geometry.

1 · The Principle of Superposition

DEFINITION

When two or more waves meet at a point, the resultant displacement is the algebraic sum of the displacements of the individual waves.

  • Waves pass straight through one another (two torch beams, two sound waves) — unlike marbles which ricochet.
  • Add displacements taking sign into account: same side of zero → bigger; opposite sides → smaller.
  • Applying it along a whole wave gives the resultant profile (complex, non-sinusoidal shapes when wavelengths differ).
COMMON TRAPSuperposition ≠ “meeting then bouncing”. Particles collide; waves pass through and add — exactly what Young used to prove light is a wave.

2 · Diffraction

DEFINITION

Diffraction is the spreading of a wave as it passes through a gap or around an edge.

  • Diffraction is greatest when the gap width ≈ the wavelength.
  • Sound (λ ≈ cm–m): bends around doorways — you hear around a corner.
  • Light (λ ≈ 5×10⁻⁷ m): needs a slit a fraction of a mm wide; a doorway is ~10⁶× too wide → no visible spreading.
  • Radio (λ ≈ km): wraps around hills & buildings; microwaves (λ ≈ 10 cm) mostly go straight (mobile masts need line-of-sight).
SOLVED · MICROWAVE OVEN

Oven window (λ = 12.5 cm) has a metal grid with gaps of a few mm. Gap ≪ λ → microwaves hardly diffract → stay trapped. Visible light (λ ~ 10⁻⁶ m) gap ≫ λ → passes straight through → you can see the food.

SOLVED · RADIO AND TV IN MOUNTAINS

Radio waves (long λ) diffract around hills → strong signal. TV (short λ, high f) barely diffracts → needs straight-line satellite reception.

3 · Interference & Coherence

DEFINITIONS

Interference = superposition of two or more waves from coherent sources.

Coherent sources: emit waves with a constant phase difference (hence same frequency, maintained).

Path difference = the extra distance one wave has travelled compared with the other.

ConstructiveDestructive
Wave arrivalin phase (Δφ = 0°)in antiphase (Δφ = 180°)
Resultamplitude = sum (louder / brighter)amplitude = difference (near zero / dark)
Path differencenλ (whole wavelengths)(n + ½)λ (odd half-wavelengths)
EXAMINER’S TRAPTwo loudspeakers on different signal generators → phase keeps sliding → the pattern moves in and out, never stable. Only equal, constant frequencies give a stable pattern. Two separate lasers usually aren’t coherent → divide one beam with two slits instead.

Remember interference works for all waves — sound, light, microwaves, water ripples. Everyday examples: coloured bands on a CD, sights of halos around lamps on foggy nights, light/dark bands seen through fabric.

4 · Path-Difference Conditions (memorise!)

CONSTRUCTIVE

path difference = nλ (n = 0, 1, 2, 3…)

waves are in phase → bright fringe / loud

DESTRUCTIVE

path difference = (n + ½)λ = (2n+1)·λ/2

waves are in antiphase → dark fringe / silence

Step 1: count the number of extra wavelengths the longer path carries.
↓
Step 2: whole number → constructive; half-integer → destructive.
↓
Step 3: flag each maximum as order n (0, 1, 2…) for grating Qs.
SOLVED · RIPPLE TANK

Two dippers A and B. Point P: A has travelled 6λ, B has travelled 6.5λ. Path difference = 0.5λ → destructive (antiphase) — water there stays flat. If both travelled 5λ → path difference = λ → constructive — big ripple.

MEMORY TRICK“Whole = bright, half = dark.” Whole wavelengths bring crests together; half wavelengths bring crest and trough together.

5 · Young’s Double-Slit Experiment

KEY EQUATION

λ = a·x / D

a = slit separation · x = fringe spacing · D = slit-to-screen distance

  • One laser beam split by two slits → slits act as coherent sources.
  • Equally spaced bright fringes = maxima (constructive); dark in between = nλ vs (n+½)λ.
  • Central bright fringe at the midpoint (path difference = 0).
  • Fringe separation: x = λD/a, so closer slits / longer λ / further screen → wider fringes.
SOLVED · LASER WAVELENGTH

He–Ne laser, 10 fringes span 1.5 cm → x = 1.5 cm/10 = 1.5×10⁻³ m; a = 1.0 mm = 10⁻³ m; D = 2.40 m.

λ = a·x/D = 10⁻³·1.5×10⁻³/2.40 = 6.25×10⁻⁷ m = 630 nm.

SOLVED · SODIUM LIGHT

Yellow 589 nm, a = 0.20 mm, D = 1.20 m: x = λD/a = 589×10⁻⁹·1.20/0.20×10⁻³ = 3.5×10⁻³ m (3.5 mm).

HOW TO IMPROVE ACCURACY
  • Use a laser: monochromatic, intense → detect fringes far away (big x, small % error).
  • Measure across several fringes (e.g. 10) then divide.
  • Measure slit separation with a travelling microscope; measure D with a tape/metre rule.

6 · Diffraction Grating

KEY EQUATION

d·sin θ = nλ

d = spacing between adjacent lines · θ = angle of broad-maxi · n = order (0,1,2,3…)

  • Grating = thousands of equal spaced slits per cm; each diffracts, all interfere.
  • Central (zeroth-order) maximum at θ = 0 (all rays in phase).
  • Bright maxima are sharp and bright (thousands of slits pulling the amplitude).
  • Longer λ → bigger sinθ → red spread further out than violet (dispersion of white light).
  • Maximum possible order: sinθ ≤ 1 → n_max = floor(d/λ); only nλ/d ≤ 1 is possible.
SOLVED · CALCULATING λ

Grating 300 lines mm⁻¹ → d = 1/300 mm = 3.33×10⁻⁶ m. First-order angle θ = 10.0°. λ = d·sinθ/n = 3.33×10⁻⁶·sin10° = 5.8×10⁻⁷ m = 580 nm.

SOLVED · HOW MANY MAXIMA?

d = 2.00×10⁻⁶ m, λ = 580×10⁻⁹ m. d/λ = 3.45 → sinθ ≤ 1 allows n up to 3. So n = 0, ±1, ±2, ±3 → 7 visible beams (minus any over the diffraction spectral end… exam-friendly to count symmetric orders).

7 · Stationary (Standing) Waves

DEFINITION

A stationary wave forms when two identical progressive waves (same amplitude & wavelength) travel in opposite directions and superpose. No energy is transferred along the medium.

  • Node — fixed point where amplitude is always zero.
  • Antinode — point of maximum amplitude.
  • Adjacent nodes (or adjacent antinodes) are separated by λ/2; node→antinode = λ/4.
ProgressiveStationary
Energytransported alongtrapped, none transmitted
Amplitudeconstant for all points0 at nodes → max at antinodes
Phaseneighbouring loop variantadjacent loops 180° out of phase
Speedv = fλeffectively zero (pattern stays)
PHASE DETAILPoints either side of a node are 180° out of phase (opposite sides of the loop move in opposite sense). The Tacoma Narrows Bridge (1940) fell when wind excited a standing wave at its natural frequency.

8 · Stationary Waves on Strings & in Air Columns

String fixed at both ends (guitar)

Nodes at both fixed ends. Harmonics have frequency f = n·f₀:

For length L and wavelength λ: λ = 2L/n (n = 1,2,3…); frequency f = v/λ = n v/2L. All harmonics allowed.

Air column, one end closed (pipe)

Closed end → node; open end → antinode. Only odd harmonics: L = (2m−1)λ/4.

Closed pipe: L = λ/4 → λ = 4L (first resonance). Closing one end of an open pipe roughly halves the frequency (λ doubles: λ/2 → λ/4).

SOLVED · RESONANCE TUBE

Tuning fork 256 Hz, first resonance L = 31.2 cm. Since closed end = node and open = antinode, L = λ/4 ⇒ λ = 4×0.312 = 1.248 m. Speed v = fλ = 256 × 1.248 ≈ 320 m s⁻¹.

SOLVED · SOUND IN AIR·KUNDT

Frequency 2500 Hz, nodes 20 cm apart → λ = 2×0.20 = 0.40 m. v = fλ = 2500 × 0.40 = 1000 m s⁻¹ (in a solid).

WORKED · INTERFERENCE OF SOUND

Two speakers 1.5 m apart; student 8.0 m away walks parallel; successive maxima 1.2 m apart. Treat D≈8.0 m, slit a=1.5 m, x=1.2 m ⇒ λ = a·x/D = 1.5×1.2/8.0 = 0.225 m; f = v/λ = 330/0.225 ≈ 1470 Hz.

WORKED EXAMPLE · HYDROGEN LINE

656-nm line on grating with 5000 lines/cm → d = 1/5000 cm = 2.00×10⁻⁶ m. n=1: sinθ = λ/d = 656×10⁻⁹/2.00×10⁻⁶ = 0.328 → θ₁ = 19.2°. n=2: sinθ = 0.656 → θ₂ = 41.0°.

WORKED EXAMPLE · STANDING MICROWAVE

Adjacent intensity maxima 14 mm apart → adjacent antinodes 14 mm = λ/2 → λ = 28 mm. f = c/λ = 3.0×10⁸ / 28×10⁻³ ≈ 1.1×10¹⁰ Hz.

10 · Mistakes · Tips · Tricks · One-Page Revision

✗ Mistake✓ Correction
“Waves bounce off each other.”They pass through and superpose (algebraic sum).
Interference needs any two sources.Native coherent sources (constant phase difference, same f).
Path difference = 2λ for destructive.Destructive needs odd half-multiples (n+½)λ; 2λ is constructive.
λ = a/x·D without units check.Always in metres: λ = a·x/D with a, x, D all in m.
Stationary wave carries energy.No net energy transfer; progressive waves do.
All harmonics in closed pipe.Closed pipe: odd harmonics only.
Node–node separation = λ.node–node = λ/2; node–antinode = λ/4.
MEMORY TRICKS
  • “Whole = bright, half = dark.”
  • λ = a·x / D — “a-X divided by D”; D is far.
  • Half-node trick: node–node = λ/2.
  • Coherent = “constant clock”. Same frequency keeps the phase constant.
  • Grating: bigger λ → bigger sinθ → red furthest out.
INTERFERENCE

constructive: Δ = nλ · destructive: Δ = (n+½)λ
coherent ⇒ constant phase difference

DOUBLE-SLIT / GRATING

λ = a·x/D · d·sinθ = nλ
d = 1/(lines per m)

STATIONARY WAVES

node: zero motion · antinode: max
node/antinode spacing = λ/2
string fixed: λ = 2L/n · closed pipe: L = (2m−1)λ/4

WAVE EQUATION

v = fλ · c ≈ 3×10⁸ m s⁻¹
path length = λ/f

PAST-PAPER STYLE Q&A

Q1. Coherent shiny sources must have constant phase difference → same frequency.
Q2. 12 fringes in 16.8 mm ⇒ one fringe = 1.4 mm; a = λD/x with λ = 590 nm, D = 1.8 m → a = 0.76 mm.
